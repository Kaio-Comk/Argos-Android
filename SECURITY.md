# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of **Argos-Android** seriously. If you discover a vulnerability:

1. **Do not create a public issue.**
2. Send an advisory report via GitHub Private Vulnerability Reporting or email `kaiocomkamil@gmail.com`.
3. Include detailed steps to reproduce the issue and affected Android API levels.
4. We aim to acknowledge reports within 48 hours and provide a fix release promptly.
